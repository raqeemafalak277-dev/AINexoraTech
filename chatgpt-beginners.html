How to get more useful results from ChatGPT

A useful AI conversation often starts with a useful instruction. A little context and a clear goal can make the response more relevant.

✧

1. Explain your goal

Tell the assistant what you are trying to accomplish. Instead of saying “help me with writing”, say “help me draft a polite email asking for a project meeting”.

2. Add relevant context

Share the audience, your current level, any requirements and constraints. For example, mention that an explanation should be suitable for a beginner or that a report must be 300 words.

3. Specify the output format

Ask for a table, checklist, short explanation, step-by-step guide or draft when a particular format will help you use the answer.

4. Improve the result

If the first response is not quite right, explain what needs changing. You can ask for simpler wording, more examples, a shorter version or a different tone.

5. Verify important information

ChatGPT can make mistakes. Check important dates, figures, citations, medical or legal information and technical instructions against trustworthy sources.

Prompt pattern: “I want to [goal]. My context is [context]. Please create [format]. Keep it [tone/level] and include [requirements].”

Final thoughts

Think of prompting as giving a clear brief to a helpful assistant. The more clearly you explain the task, the easier it is to evaluate the response.
