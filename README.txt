AINexoraTech - Multi-page technology blog starter

HOW TO RUN
1. Extract this ZIP file.
2. Open the AINexoraTech folder in Visual Studio Code.
3. Install the Live Server extension if it is not installed.
4. Right-click index.html and choose Open with Live Server.

SEPARATE NAVIGATION PAGES
Home: index.html
AI Tools: ai-tools.html
AI Insights: ai-insights.html
Technology: technology.html
Tutorials: tutorials.html
All Articles: articles/index.html
About: about.html
Contact: contact.html

DESIGN
Dark navy / midnight blue, electric blue, cyan and violet accents. Category landing pages use editorial photography loaded from Unsplash image URLs, so an internet connection is needed to display those photos.

IMPORTANT
The contact and newsletter interactions are front-end demonstrations only. Connect a form service or backend before collecting visitor information. Replace sample article content with original, fact-checked posts before publishing. Update sitemap.xml if you change the domain or add pages.


CONTACT PAGE
The Contact page displays the site owner's supplied email and WhatsApp number.
The form can prepare a message in WhatsApp or the visitor's email application.
The visitor must press Send in that app. A static website cannot silently deliver
messages to WhatsApp and email. For server-side form delivery, connect a trusted
form service or build a backend before launch.
